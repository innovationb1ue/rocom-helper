# 属性克制矩阵数据差异报告

## 状态：已解决 (2026-05-05)

本报告中的所有差异已根据 BWIKI 权威数据完成修正。

## 修正来源

- **BWIKI 克制计算器**: https://wiki.biligame.com/rocom/克制计算器
- **最后更新**: 2026-04-07
- **交叉验证**: 游戏内部数据 `data/game/attr_map.json` 确认了18个属性类型及其名称

## 修正内容

### 类型系统变更 (21 → 18)

| 变更 | 说明 |
|------|------|
| 移除 石 (id:11) | 新游戏中不存在石属性 |
| 移除 神火/神水/神草 (id:18-20) | 新游戏中不存在神属性 |
| 新增 幻 (id:11) | 新游戏中的幻属性，复用原石属性ID |
| 土 → 地 | 游戏内名称为"地" |
| 幽灵 → 幽 | 游戏内名称为"幽" |
| 恶魔 → 恶 | 游戏内名称为"恶" |

### 克制数据修正

所有18个属性的克制/抵抗关系已完全按照 BWIKI 计算器的 JavaScript 数据重建，包括：

1. **移除宝可梦逻辑**: 电vs地、幽灵vs普通、武vs幽灵 从免疫(0.0x)改为抵抗(0.5x)
2. **修复龙系抵抗缺失**: 火/水/草/电 均添加了对龙的抵抗(0.5x)
3. **修复机械系抗性**: 多个属性添加了对机械的抵抗
4. **光属性激活**: 光从无克制关系改为克幽/恶，被草/冰抵抗
5. **萌属性修正**: 萌克龙/武/恶，被火/毒/机械抵抗
6. **新游戏无免疫关系**: 所有倍率均为 0.5x 或 2.0x，不存在 0.0x
